= Yet Another C++ Standard Library

YACSL is a C\++ standard library designed for ease of use and performance. It uses error enums instead of throwing exceptions. Many corners are cut and assumptions are made to make the code shorter and faster, but at least if you compile in debug mode, most problems should lead to a crash with a stacktrace. This project's only dependency is libc, (not libc++). 
As YACSL is still very early in development, there is no stable API yet and there will be many large refactors.

:toc:
== Dependencies
- libc
- a c/c++ compiler
- cmake 3.28+

== Installation
[source,sh]
----
git clone https://codeberg.org/ThomasReal/base.git
cd base
cmake -B build -DCMAKE_INSTALL_PREFIX=<your_prefix> -DCMAKE_BUILD_TYPE=Release
cmake --build build
----

== Testing
[source,sh]
----
cd build/tests/
ctest --output-on-failure 
----

== Emscripten
You can compile with emscripten using emcmake for the configure step:
[source,sh]
----
emcmake cmake -B build -DCMAKE_INSTALL_PREFIX=<your_prefix> -DCMAKE_BUILD_TYPE=Release
----
