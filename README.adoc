= Yet Another C++ Standard Library

YACSL is a minimal C\++ standard library designed for ease of use and performance.
This project's only dependency is libc, (not libc++).
It uses error enums instead of throwing exceptions. There are many edge cases where the library panics(crashes) because is it designed to be smaller and less extensive alternative that has faster hot paths.
As YACSL is still very early in development, there is no stable API yet and there will be many large refactors.

:toc:
== Dependencies
- libc
- a c/c++ compiler
- cmake 3.28+

== Building
[source,sh]
----
git clone https://codeberg.org/ThomasReal/base.git
cd base
cmake -B build -DCMAKE_INSTALL_PREFIX=<your_prefix> -DCMAKE_BUILD_TYPE=Release
cmake --build build
----

== Testing
[source,sh]
----
cd build/tests/
ctest --output-on-failure 
----

== Emscripten
You can compile with emscripten using emcmake for the configure step:
[source,sh]
----
emcmake cmake -B build -DCMAKE_INSTALL_PREFIX=<your_prefix> -DCMAKE_BUILD_TYPE=Release
----
