== Base

Base is a general purpose c++ library designed for speed and no dependencies. It can be built with or without libc++ using the meson build system. If you plan to use this library, know that it is not guaranteed to stable or even to have all commits tested. This project is still early in developpement and I think that it is better to wait before deciding on one stable api. If you still want try this library, look at the tests for examples.

:toc:

== Dependencies
- a c++ compiler
- meson

== Installation
[source,sh]
----
git clone https://codeberg.org/ThomasReal/base.git
cd base
meson setup build --buildtype=release --prefix=[YOUR_PREFIX]
meson install -C build
----

== Testing
[source,sh]
----
meson test -C build
----
